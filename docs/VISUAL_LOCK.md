# Visual lock — Chatpattoytv RC Game

This document records the agreed art direction. New work must preserve it.

## Direction
A premium, realistic RC monster-truck simulator inspired by the user's RC content and the broad class of large 8S RC trucks. The game uses original vehicle geometry, paint, body details and names. Do not copy manufacturer logos, trademarks or exact protected bodywork.

## Keep
- Large RC monster truck stance, oversized tyres and visible long-travel suspension.
- Realistic off-road setting: dirt, rocks, mountain silhouettes, forest edges, climbs, ramps, mud and water areas.
- Third-person chase camera plus close bonnet camera.
- Minimal dark HUD with restrained warm highlights.
- Landscape-first Android touch controls.

## Never change to
- Cartoon, low-poly, childish or toy-store visual style.
- Ordinary full-size monster trucks or small road cars.
- Bright cluttered menus or arcade-only presentation.

## Asset source of truth
At project kickoff, the game repository contained only README.md; no game reference photographs were present in the repository. This art lock records the agreed written direction. When approved game reference screenshots are added to this repository, use them as the more precise visual source of truth.
